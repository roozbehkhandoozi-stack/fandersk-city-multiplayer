# فندرسک سیتی — نسخه چندنفره

این پروژه نسخه‌ی عمومی چندنفره‌ی فایل HTML اصلی است. حرکت بازیکنان، ماشین، ظاهر، چت و رویداد دستگیری از طریق WebSocket همگام می‌شود و حساب‌ها/پیشرفت بازی در `data/db.json` ذخیره می‌شوند.

## اجرا روی کامپیوتر
1. Node.js 18 یا جدیدتر نصب باشد.
2. در پوشه پروژه اجرا کنید: `npm install`
3. سپس: `npm start`
4. مرورگر: `http://localhost:3000`

برای تست چندنفره، همین آدرس را در دو مرورگر/دستگاه باز کنید.

## انتشار عمومی
این پروژه را روی یک هاست Node.js که WebSocket و دیسک پایدار دارد منتشر کنید. فرمان اجرا `npm start` و پورت از متغیر محیطی `PORT` خوانده می‌شود.

## نکته امنیتی
این نسخه برای شروع و بازی دوستانه ساخته شده است. سیستم حساب فایل اصلی حفظ شده و هش رمز سمت مرورگر تولید می‌شود. برای انتشار بزرگ و عمومی بهتر است احراز هویت و اعتبارسنجی اقتصاد بازی به سرور منتقل شود.
